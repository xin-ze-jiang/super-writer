super-writer

给主流 AI 编程工具用的一组技能：LaTeX 论文排版、赛级 PPT 生成、中文 AI 绘画提示词。 每个技能都是自包含目录，复制进去就能用，不需要改代码。

  • MIT
  • SKILL.md 标准格式
  • 纯本地运行
  • 一条命令安装
  • 9 个工具通用
Windows · PowerShell在任意目录执行
git clone https://github.com/xin-ze-jiang/super-writer.git cd super-writer powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Target auto
macOS / Linux · Bash在任意目录执行
git clone https://github.com/xin-ze-jiang/super-writer.git && cd super-writer && ./install.sh --target auto

-Target auto 只装检测到的工具；要全装用 all，也可指定 claude,cursor 等。 重复执行原地覆盖，不会产生重复目录。

01

四个技能

技能靠 SKILL.md 的 description 匹配，用日常说法就能触发，也可以直接输入斜杠命令。

TEX

latex-paper

LaTeX 论文排版：10 套现成模板，选题材、复制、改内容，一条命令跑完 XeLaTeX + bibtex/biber 出 PDF。

  • 中文课程论文、实验报告、作业、数模国赛、本科毕业论文
  • IEEE / ACM 会议、美赛（MCM/ICM）
  • Elsevier 与 IEEE 期刊投稿
  • 顺带排查 LaTeX 报错、改字号与页边距
试试说：把这份实验报告排成 PDF
▤

sj-ppt

赛级 PPT 生产线：把内容写进一个 deck.json，同时生成单文件 HTML 演示和可编辑 .pptx。

  • 一套内容源，两版交付
  • 内置 5 套风格，数字滚动、柱状生长、逐项入场动效
  • 自带静态检查：溢出、缺字段、字号过小
  • 适合答辩、大创汇报、课程汇报
试试说：用 sj-ppt 做一个 12 页答辩 PPT
✎

promptlab

中文 AI 绘画提示词工坊：按七段式写提示词，用锚点保证系列图一致，自带自检脚本。

  • 主体 → 动作构图 → 镜头 → 光线 → 材质风格 → 氛围 → 画幅
  • 角色卡 / 世界卡，跨图保持一致
  • 自检空话、维度冲突、画幅缺失
  • 概念图、角色三视图、绘本分镜
试试说：帮我写/改一条即梦提示词
▦

coordinate-plot

坐标纸出图：把实验数据画成 1mm 真实毫米格的曲线图，打印后照着数格子往纸质坐标纸上手绘。

  • 1mm 细格 / 5mm 中格 / 10mm 粗格，网格与刻度同源
  • 折线 / 平滑 / 线性拟合（标斜率、截距、R²）/ 散点
  • 上下 1~2 个子图，多列叠画，中文轴标签与单位
  • 黑白打印优先，300dpi PNG，打印选「实际大小」即真毫米
试试说：把这组实验数据画成坐标纸图

依赖与常见坑

四个技能互不依赖，可以只装其中一个。跑不动时先对照下表。

依赖

依赖用在哪缺了会怎样
TeX Live 2026 完整版latex-paper编译直接失败
xelatex / bibtex / biber 在 PATHlatex-paper报找不到命令
PowerShell 5.1+latex-paper 的 build.ps1脚本跑不起来
Node.js 18+sj-ppt 生成 HTML报 node: command not found
Python 3.8+sj-ppt 生成 pptx；promptlab 自检；coordinate-plot 出图脚本无法启动
python-pptx、lxmlsj-ppt 生成 pptxModuleNotFoundError
matplotlibcoordinate-plot 出图导入报错，无法出图；中文缺字会变方块

常见坑

现象原因 / 处理
技能装了不生效多套了一层目录，SKILL.md 必须在技能目录根
xelatex 不是命令TeX Live 的 bin 目录没进 PATH
中文乱码 / 缺字.tex 存成 UTF-8；.ps1 要 UTF-8 带 BOM
参考文献显示 [?]没跑 bibtex/biber，或 refs.bib 里没有对应 key
deck.json 解析失败文件带 BOM 或存成 GBK，用 UTF-8 重存
pptx 提示「需要修复」只改 deck.json 再重新生成，别手改 pptx
