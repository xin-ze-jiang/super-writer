# PromptLab · 中文提示词工坊

给即梦 / Seedream 写中文提示词，默认目标工具是**即梦（免费版）**。核心不是"把话说漂亮"，而是**用固定锚点锁住不变的部分，只改变化的部分**。

## 一、何时启用 / 不启用

**启用**：用户要写或改 AI 绘画提示词；做场景概念图；做数字人 / 角色设定 / 三视图；做绘本分镜、故事插画；做可进入的 3D 空间前期概念；任何"这组图要长得像同一套"的需求。

**不启用**：写代码、做报表、做 PPT 排版、纯文字写作、与出图无关的图片处理（裁剪、压缩）。

## 二、执行流程（五步，按序，不许跳）

### ① 判定意图与参数（先问清，再动笔）

先归到四类之一：**场景 / 角色 / 绘本 / 3D 空间**（或组合）。再判断走哪条分支：

| 需求 | 分支 |
|---|---|
| 普通出图（场景 / 角色 / 绘本 / 3D） | 直接走七段式（③） |
| 影视感 / 分镜表 / 运镜 / 镜头语言 | 先读 `references/cinematic.md` 做机位决策，再套七段式 |
| 动效短片（要 mp4、卡点、逐帧渲染） | 读 `references/motion.md`，不走七段式，产物是时间轴 + 渲染 |
| 混合（绘本分镜 + 动效） | 先用 cinematic 定镜头，再用 motion 定每镜头拍数 |

缺以下参数就问，一次问完，不超过 3 个问题：

- 画幅：竖版 3:4 / 方图 1:1 / 横版 16:9（绘本默认竖版）
- 目标工具：默认即梦；若用户用别的工具，只改"适配层"，不改锚点
- 数量：单图 / 系列几张 / 绘本几页

用户答"随便/好看就行"时，给 2~3 个具体选项让其选，不要自行决定。

### ② 先写一致性锚点（不参与后续改写）

- 角色任务 → 写**角色设定卡**（8 字段固定顺序，见 `references/consistency.md`）
- 场景 / 3D 任务 → 写**世界设定卡**（世界观 / 建筑语汇 / 材质体系 / 主色 / 时代细节 / 天气 / 镜头风格）
- 绘本任务 → 角色卡 + 世界卡都要

锚点一旦定稿，后续每一页**逐字复制**，连标点都不改。改锚点 = 换人/换世界。

### ③ 按七段式生成提示词

顺序即权重，越靠前越难被忽略：

```
主体 → 动作与构图 → 镜头 → 光线 → 材质风格 → 氛围 → 画幅
```

- 主体必须是第一句，且第一句就说清"谁 + 在做什么"
- 每个维度最多 2 个修饰词
- 风格词只写一种，且固定在同一位置、同一措辞
- 画幅写在句末（如"画幅 3:4"）

需要词条时查 `references/visual-codex.md`（六维度可直接复制的词条 + 冲突清单），不要临场编形容词。

**影视类硬步骤**：先做机位决策，再选焦段。顺序是"机位 → 距离 → 遮挡 → 高度 → 焦段"，焦段只写一个；不许用"85mm"代替"摄影机站在哪"。细则见 `references/cinematic.md`。

**英文提示词**：同样先主体后画面，但按英文习惯写完整句，不逐词对译中文。长度标准另算（见 ④）。

### ④ 过自检脚本 + 10 条清单

```bash
# 先 cd 到技能目录再执行
python scripts/check_prompt.py -p "你的提示词"
python scripts/check_prompt.py -f prompt.txt          # 从文件读
python scripts/check_prompt.py -b prompts.txt         # 每行一条，批量
python scripts/check_prompt.py --lang en -p "your prompt"   # 强制英文模式
```

脚本检查：字数 60~120（英文 40~80 词，超 100 词提示删减）、否定词、无效画质词、主体是否在第一句、画幅/镜头/光线三要素、重复与近义词堆叠，给出得分与"必须改"项。`--lang` 取 `zh` / `en` / `auto`，默认 `auto` 按汉字与英文词占比判定。

**不通过就改，改完再跑一次**，不许把未过检的提示词交付。

清单 10 条（与脚本互补，人工判断）：

1. 前 15 字说清"谁 + 在做什么"
2. 每个形容词都能对应一个看得见的结果
3. 没有哪个维度堆了 3 个以上修饰词
4. 没有互斥词（广角+长焦、逆光+正面清晰、高饱和+莫兰迪）
5. 没有否定句
6. 没有无效画质词
7. 风格词只有一种且位置固定
8. 主光方向 + 受光部位写清
9. 一致性任务：锚点一字未改，只换了动作/环境/镜头
10. 总长 60~120 字（英文 40~80 词）

### ⑤ 交付

交付三样，缺一不可：

1. **可直接复制的提示词**（纯文本，不加解释，方便整段粘贴）
2. **设定卡**（角色卡或世界卡，同系列后续复用）
3. **一句"这条改了会影响什么"**：例如"把 35mm 改成 85mm，脸会更自然、背景更虚，但巷子的纵深会丢"

## 三、硬规则（写死，不许违反）

1. **主体第一句**，第一句必须含"谁 + 在做什么"
2. **总长 60~120 字（英文 40~80 词）**；超 200 字各维度互相稀释，要更多信息就分次生成
3. **不写否定句**：把"背景不要杂乱"改成"背景简洁，主体周围留空"
4. **不堆画质词**：8K / 超高清 / 超精细 / 杰作 / 大师作品 / 最佳画质 / 电影级画质 一律删；英文同理，8k / ultra detailed / masterpiece / best quality / hyperrealistic 都不写
5. **中文表述**，术语给中文写法（不写"次表面散射"，写"皮肤透光，边缘透红"）
6. **一致性靠锚点 + 参考图，不靠改写描述**；锚点逐字复用，不用同义词"优化"
7. **参考图必须写两段**："参考什么" + "生成什么"；多图必须编号指名（图1 人物 / 图2 背景 / 图3 风格）
8. **一张图一个主光**，光向写"画面方向 + 受光部位"，跨页不改方向

## 四、禁止事项

- 不许把 references 的内容整段倒进回答；按需查、按需引
- 不许自造即梦没有的按钮名、菜单名、参数名（参考图权重、负面提示词强度等官方未公开，不要编）
- 不许在用户没确认参数前，直接产出整套绘本 / 整套分镜
- 不许用"高级感 / 氛围感 / 电影感"这类空词充数
- 不许交付未过自检脚本的提示词

## 五、文件地图

| 文件 | 什么时候用 |
|---|---|
| `references/visual-codex.md` | 缺词：构图 / 镜头 / 光线 / 色彩 / 材质 / 风格，六维度词条与冲突清单 |
| `references/consistency.md` | 做系列：角色卡 8 字段、世界卡、只写增量、轴线与光向 |
| `references/cinematic.md` | 影视 / 分镜：机位决策六步、五段式骨架、中英术语表、剪辑节奏 |
| `references/motion.md` | 动效短片：四层结构、按拍定镜头、七条工程注意点、适用边界 |
| `references/methods.md` | 想了解规则出处（BFL / shotkit / huashu / Seedream 官方） |
| `templates/scene.md` | 场景概念图：同一世界不同区域 |
| `templates/character.md` | 数字人 / 角色设定卡 + 三视图 |
| `templates/storybook.md` | 绘本分镜页：页号—画面—旁白—锚点复用 |
| `templates/world3d.md` | 3D 空间前期概念，交付给 Blender 用 |
| `scripts/check_prompt.py` | 自检，可批量 |
| `examples/before_after.md` | 改写对照，含失效原因 |

## 六、输出风格

- 不提"提示词工程"之类术语讲解，直接给可用的词
- 一次只改一个变量，便于用户判断哪句起了作用
- 用户原始描述里的专有名词（人名、地名、品牌）保留，不要替换成泛称
