# 改写对照（8 组）

每条“改后”都能直接粘进即梦。括号里是失效原因，不是审美评价。

## 1 形容词堆砌

- 原：`超唯美、超精致、顶级画质、大师级、电影感、8K、杰作、细节丰富、震撼`
- 改：`一个穿校服的女生坐在教室窗边翻绘本，身体微微前倾，午后侧光从窗外落在侧脸，窗外是空教室，背景虚化成柔和光斑，85mm 胸口机位，主色米白与浅蓝，画幅 4:3。`
- 原因：形容词不携带可绘制信息，模型只能回退到平均值；删掉后字数腾给主体、镜头、光线。

## 2 否定句

- 原：`一片草地，背景不要杂乱，人物不要看镜头，避免出现文字`
- 改：`一个女孩坐在草地中央，低头编草环，四角有虚化的白色野花，背景简洁，远处是模糊的山脊线，视线落在手上，午后柔光从身侧照来，主光来自画面右上，50mm 齐眼机位，浅景深，主色草绿与米白，画幅 1:1。`
- 原因：即梦对否定词识别弱，容易反向加强；一律写“要什么”，不写“不要什么”。

## 3 画质词占字数

- 原：`8K 超高清 超精细 杰作 大师作品 最佳画质 电影级画质，一只猫趴在窗台`
- 改：`一只橘猫趴在南向窗台，尾巴垂下，下午侧光穿过纱帘落在毛面，毛发边缘透光，浅景深背景虚化，50mm 齐眼机位，窗台是浅木色，旁边放一只白色陶瓷水杯，主色暖黄与米白，画幅 4:3。`
- 原因：分辨率由工具决定，画质词不改变画面；“精细感”靠主体锐利 + 背景虚化制造。

## 4 风格互斥

- 原：`莫奈油画风格，超写实摄影，赛博朋克，水墨，3D 渲染，一个女孩站在门口`
- 改：`一个女孩站在便利店门口，冷白灯与霓虹反光映在侧脸，湿地面反射招牌，玻璃门上贴着一张手写价目表，中景，35mm 胸口机位，浅景深，赛博朋克摄影风格，暗部青蓝、亮部洋红，画幅 16:9。`
- 原因：多个媒介同时出现会让模型折中，得到“什么都不像”；一张图只留一个风格词。

## 5 主体被压后

- 原：`电影感，画幅 16:9，8K，浅景深，暖色调，一个男人走在雪地里`
- 改：`一个穿深灰大衣的男人走在积雪的林间小路，脚印拖在身后，回头望向远处木屋，中景，主体偏左三分之一，35mm 胸口机位，黄昏侧逆光，主光来自画面左上，轮廓光勾出发丝，冷蓝阴影配暖橙亮部，画幅 16:9。`
- 原因：词序即权重，风格与画质词占开头会把主体挤到低权重区。

## 6 伪结构化标签

- 原：`Subject: girl. Style: anime. Lighting: soft. Constraints: no text`
- 改：`一个扎双马尾的女孩站在旧书店门口，抱着一摞书，日系插画风格，柔和散射光，背景是虚化的木质书架，书架上有旧书和一只睡着的橘猫，地上堆着两摞书，浅景深，画幅 3:4。`
- 原因：中文模型按自然语言训练，伪字段会被当正文读，占字数还不生效（社区红线，官方未提）。

## 7 一页塞多镜头

- 原：`第一页她在门口，然后走进教室，然后坐下翻开书，最后看向窗外`
- 改：`一个女孩推开教室门站在门口，逆光，书包带滑到肩下，教室里有几排空课桌，中景，35mm 胸口机位，清晨低角度侧光，主光来自画面左上，儿童绘本插画风格，画幅 4:3。`
- 原因：单图只承载一个时间点；连续动作拆到下一页，否则压成混乱构图。

## 8 编辑指令指代模糊

- 原：`让它变成粉色，背景换掉，其他不变`
- 改：`参考图1：参考人物五官、发型与服装；生成：把人物围巾改为粉色，背景换成浅灰墙面，其余构图、动作、光线保持完全一致。`
- 原因：模糊代词会让模型改错对象；写清“变化动作 + 变化对象 + 变化特征”，并强调其余不变。

## 对照速查

| 失效类型 | 一句话修法 |
|---|---|
| 形容词堆砌 | 换成可指认的参照物（米白墙面、细木格栅） |
| 否定句 | 改正向描述 |
| 画质词 | 全删，用“主体锐利 + 背景虚化” |
| 风格互斥 | 只留一个风格词，位置固定 |
| 主体靠后 | 主体提到第一句 |
| 伪结构标签 | 改成中文连贯句 |
| 多镜头挤一页 | 拆页，一页一个瞬间 |
| 指代模糊 | 点名对象 + 强调其余不变 |
