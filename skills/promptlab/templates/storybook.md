# 模板 · 绘本分镜页（页号—画面—旁白—锚点复用）

用途：8~16 页连续绘本，页与页之间角色和世界不漂移。文字后期排版，不交给模型画。

## 前置：两张锁

```
角色锁：<设定卡 8 字段原文>
场景锁：<世界设定卡原文>
画风锁：<一句风格词，位置固定>
画幅锁：<统一 4:3，全程不换>
轴线：<A 在画面左侧，B 在画面右侧>
光向：主光来自画面左上，人物右脸受光
```

## 每页表（先填表，再写提示词）

| 页 | 画面（一个瞬间） | 旁白（后期贴字） | 锚点复用 |
|---|---|---|---|
| P1 | 女孩蹲在雨后巷口水洼边，捧起落叶，抬头惊讶，近景 | 那天雨刚停。 | 角色锁 + 场景锁原文 |
| P2 | 女孩奔跑穿过菜市场，右手举糖葫芦，回头笑，中景 | 她想快点回家。 | 同上，仅换动作与环境 |
| P3 | … | … | … |

分镜纪律：
- 一页一个时间点，不写"然后……然后……"。
- 旁白单独成列，不进提示词；要画进画面的文字才加双引号并写位置。
- 景别可以在页间变化，轴线不许翻。

## 单页提示词（循环使用）

```
<角色锁 + 场景锁 + 画风锁原文，一字不改>
本页画面：<页号对应的单一动作与表情>；<景别>，<主体在画面左/右三分之一>；
镜头：<焦段 + 机位，系列内尽量固定>；
光线：主光来自画面左上，<本页时间 + 光质>；
画幅：<画幅锁>。
```

## 出图后核对 3 点

脸型 → 发型 → 标志物。任一不符就重抽，别指望后期修。

## 交付三样

1. 分镜表（页号/画面/旁白/锚点）
2. 每页完整提示词
3. 一句话："把画幅从 4:3 改成 16:9，会重新构图，脸也会跟着变，整套要重出。"
