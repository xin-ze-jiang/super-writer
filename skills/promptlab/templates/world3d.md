# 模板 · 3D 空间前期概念（给 Blender 用）

用途：进 Blender 之前，先定空间关系、视角与尺度，避免建模到一半发现透视和比例不对。
产出不是效果图，是**能对照建模的参考图**。

## 提示词骨架

```
<空间类型，如：旧厂房改造的挑高展厅>，
<平面布局：正中一条长桌，两侧各三排货架>，
俯视等轴测视角，45 度平行投影，无近大远小，
<尺度参照物：门口站一个 1.7 米高的人，长桌约 4 米>，
<结构关系：承重柱四根，屋顶桁架横跨>，
材质：清水混凝土墙面、深灰钢梁、浅木桌面，表面有气孔与轻微磨损，
光线：均匀环境光 + 顶部两盏射灯，主光来自画面左上，阴影柔和，
画幅 16:9。
```

要点：
- 一定要写**尺度参照物**（人/门/桌），否则模型给的是无尺度抽象图。
- 一定要写**平行投影/等轴测**，要透视的图没法当建模参考。
- 材质只写 3 种主材质，多了看不出结构。
- 不写人物动作，人物只作比例尺。

## 出图后转成建模输入

| 图上要素 | Blender 里对应 |
|---|---|
| 平面布局 | 顶视图对齐（Top View 截图对照） |
| 层高与柱距 | 用参照物换算成米，先建灰盒（graybox） |
| 主光方向 | 建一盏 Sun，方向照图放 |
| 材质分区 | 按块赋基础材质，不追细节 |

## 交付三样

1. 概念图提示词（含尺度参照）
2. 一张换算表（图上比例 → 实际米数）
3. 一句话："把 45 度等轴测改成透视镜头，这张就不能当建模参考了。"
