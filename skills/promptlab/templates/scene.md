# 模板 · 场景概念图（同一世界，不同区域）

用途：给一部片/一个项目做 3~7 张同一世界的场景图，要求不同区域但同一套视觉语言。

## 第一步 世界设定卡（只写一次，之后逐字复制）

```
世界观类型：<近未来东亚城市 / 蒸汽朋克港城 / 西南山村>
建筑语汇：<白墙、木格栅、圆形暖光灯 / 铸铁桁架、铆钉、砖拱>
材质体系：<金属与竹材混用 / 石材与锈铁>
主色三色：<米白、深灰、暖橙>
时代科技细节：<街灯是悬吊圆灯，无屏幕广告 / 有蒸汽管道与压力表>
天气基调：<常年阴天 / 干燥多尘>
固定镜头：<35mm 视角，胸口机位 / 等轴测 45 度>
风格词：<电影场景概念设计，前中后景分层>
```

## 第二步 单张提示词（七段式填空）

```
<世界设定卡原文，一字不改>
动作与构图：<本次区域的地标动作，如：货船停靠在窄水道，码头工人搬运木箱>；主体位于<位置>，<前景/中景/远景>分层
镜头：<焦段 + 机位 + 虚实>
光线：主光来自画面<左上/右上>，<时间 + 光质>
材质风格：<本次区域材质，沿用体系：青砖→瓦片必须同语汇>
氛围：<安静忙碌 / 潮湿压抑>
画幅：<16:9 / 4:3>
```

## 换区域规则

- 只换**地点名词与本次动作**。
- 材质不能换体系：巷子青砖 + 木格栅，屋顶就用瓦片 + 木栏杆，不许突然出现玻璃幕墙。
- 主色三色必须原样出现，至少两个。
- 光向固定在同一侧，只允许改强度和色温。

## 交付三样

1. 世界设定卡（可直接复制）
2. 每张的完整提示词
3. 一句话："换掉主色三色里的暖橙，整组会从生活感变成冷峻科幻感。"
