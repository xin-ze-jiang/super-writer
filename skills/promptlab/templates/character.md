# 模板 · 数字人 / 角色设定卡 + 三视图

用途：先出一张"标准件"，后续所有图都引用它。设定卡字段顺序固定，不许调换。

## 设定卡（8 字段，按序写死）

```
1 身份年龄：<12 岁中国女孩 / 28 岁男性机械师>
2 脸型五官：<圆脸，单眼皮，深棕杏仁眼，眉细而平，鼻梁低，薄唇上唇略翘，左颊一颗小痣>
3 发型：<黑色直发过肩，齐刘海，发尾内扣，右侧一枚黄色小鸭发夹>
4 体型：<瘦小，肩窄，四肢偏细>
5 标志物：<左手腕红绳 / 旧皮质护目镜>
6 服装：<米白圆领棉麻短袖，袖口浅蓝细边；深蓝宽松短裤；细棕皮带>
7 主色：<米白、深蓝、暖黄>
8 画风：<儿童绘本插画，柔和水彩上色，圆润造型，手绘线条>
```

顺序理由：越不可变的越靠前。脸和发型在前，换场景时模型优先保脸；服装放最前，模型会为了配衣服重新捏脸。

## 提示词 A｜角色三视图（先做这张）

```
<设定卡原文全段，一字不改>；
角色设定图，纯色浅灰背景，正面全身站姿，双臂自然下垂，面无表情；
同一画面并列正面、侧面、背面三个视角，人物比例一致；
柔和均匀正面光，无戏剧阴影；
画幅 4:3。
```

## 提示词 B｜正式用图（之后每张）

```
参考图1：<设定卡标准件>，参考其脸型、五官、发型、标志物与配色；
生成：<角色名> <动作>，<表情>，位于<环境>，<景别>，主光来自画面<左上>，<时间 + 光质>，<画幅>。
```

铁律：设定卡一字不改；只写增量（动作/表情/环境/镜头）；参考图必须写"参考什么 + 生成什么"两段。

## 交付三样

1. 设定卡（可复制）
2. 三视图提示词 + 正式图提示词
3. 一句话："把第 2 字段里的'单眼皮'改成'双眼皮'，等于换人，整套图都要重出。"
