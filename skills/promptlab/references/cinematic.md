## 一、机位决策六步（顺序不能倒）

**核心一句：不要用镜头选择代替机位思考。** 先决定摄影机站在哪，再决定用什么焦段。

| 步 | 问什么 | 输出 |
|---|---|---|
| 1 机位 | 这个空间里，摄影机实际能站在哪？门口、走廊尽头、车顶、水下、天花板 | 一个具体位置 |
| 2 距离 | 极远 / 远 / 中 / 近 / 细节，五档选一 | 一个距离档 |
| 3 遮挡 | 站在这里，前景挡住什么？必须看见什么？挡住的要不要挪 | 保留 / 清除的前景清单 |
| 4 高度 | 齐眼 / 俯拍 / 仰拍 / 贴地 / 顶拍 | 一个高度角 |
| 5 焦段 | 最后才选：24-32 / 35-50 / 85-135 / 微距 | 一个焦段 |
| 6 落笔 | 提示词先写"机位 + 距离 + 高度"，焦段只写一个 | 第一句 |

**焦段用途表**

| 焦段 | 效果 | 适合 |
|---|---|---|
| 24-32mm | 展示空间与贴近感，夸张远近关系 | 窄室内、建筑、环境压迫感 |
| 35-50mm | 接近人眼，叙事中性 | 常规叙事、对话 |
| 85-135mm | 压缩空间，背景虚，人物被"提"出来 | 人像、孤立主体 |
| 100mm 微距 | 材质与细节占满画面 | 纹理、产品、昆虫 |

**反例**：一上来写"85mm 长焦"，但机位在墙角、主体被柱子挡住——焦段对了，画面还是废的。
**正例**：先写"摄影机在巷口地面高度，距主体 4 米，前景留一段湿砖墙"，再写"35mm"。

## 二、中文五段式骨架（规划用，不是成品顺序）

写之前先把素材拆成五段，避免边写边想：

| 段 | 写什么 |
|---|---|
| 1 核心主题 | 镜头类型 → 题材 → 美学参考，3~6 个标签 |
| 2 主体与动作 | 谁 + 正在做什么 + 情绪落点 |
| 3 环境与道具 | 空间、时代细节、前景/背景各一件 |
| 4 光线与色彩 | 光位 + 时间 + 主色 3 个 |
| 5 技术参数 | 景别、焦段、机位、画幅 |

**注意**：成品提示词仍按"主体第一句"落笔（见 SKILL.md 七段式），五段式只是准备阶段的分类，不是让你把"核心主题"放第一句。

### 描述缺陷 = 描述真实（为什么）

完美无瑕的表面没有信息量，模型会把它抹成塑料感；写具体瑕疵等于给模型可落笔的锚点：

- 人物：面部细小雀斑、发丝飞散、袖口磨边
- 装备：战损、掉漆、关节油污、缝线外露
- 场景：墙皮脱落、地砖裂缝、玻璃指纹

规则：**每个主体或道具段至少 2 处瑕疵**。这不是"丑化"，是让同一件旧物在下一张图里还能被认出来。

## 四、剪辑节奏要点

| 要点 | 写法 |
|---|---|
| 镜头长度跟情绪走 | 情绪越强，镜头越短；需要读信息时放长 |
| 切点选在动作中段 | 手抬到一半切，不要等动作做完 |
| 单张图不写切点 | 一张图塞多镜头只会糊；切点只写进视频提示词 |
| 快切段落 | 4~8 拍一个镜头（和 `motion.md` 同一口径） |
| 节奏先定再写画面 | 先定时长/拍数，再决定镜头里放什么 |

**Murch 六准则**（情绪 > 故事 > 节奏 > 视线 > 二维位置 > 三维空间）：社区仓库引用，原文未核实，按"社区经验"用，不要当官方结论。

## 五、写影视类提示词时的自检 5 条

1. 机位写了吗？（不是只写焦段）
2. 前景挡了什么，写清了吗？
3. 一张图只有一个镜头、一个切点为零？
4. 瑕疵至少 2 处？
5. 焦段只出现一个，且和机位距离不矛盾？
