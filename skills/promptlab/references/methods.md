# 外部方法论精要（吸收版）

只留能落地的结论。标注来源与核实程度，避免把社区经验当官方事实。

## 1 BFL 结构公式（Black Forest Labs 官方技能）

`[Subject] + [Action/Pose] + [Style/Medium] + [Context/Setting] + [Lighting] + [Camera/Technical]`

- 用途：当七段式不知道怎么写时，用它兜底排序。
- 与中文七段式的差别：BFL 把"风格"放在第三位，中文建议放后段（避免风格抢主体权重）。
- 附带两件工具的思路：**prompt-doctor**（先诊断哪一段缺失，再补）与 **keyframes**（同一主体跨图只改镜头）。
- 核实：仓库正文已核实（MIT）。

## 2 shotkit 五层 + 系列锁

| 层 | 内容 | 中文落地 |
|---|---|---|
| 1 Brand Lock | 品牌/系列不可变的视觉资产 | 世界设定卡（世界观/建筑语汇/材质/主色/固定视角） |
| 2 Series Lock | 本系列逐页不变的角色与场景描述 | 角色设定卡 + 场景锁，**逐字照抄**，不换同义词 |
| 3 Shot Spec | 本页镜头：景别/机位/动作/表情 | 七段式里的②③④段 |
| 4 Text Layer | 画面文字 | **不进提示词**，后期排版贴字 |
| 5 Generator Adapter | 按生成器改写措辞 | 即梦 → 中文连贯句；其它工具换语法，锁本身不动 |

- 核心纪律：Series Lock 换一个同义词（齐刘海→平刘海）就等于换人。
- 核实：仓库正文已核实（Apache-2.0）。

## 3 huashu 中文短句原则

- 中文短句、主谓明确，不用伪结构标签（`Subject:` / `Style:` / `Negative:` 这类字段会被当正文读，占字数还不生效）。
- 形容词换成**可指认的参照物**：不写"高级感"，写"米白墙面、细木格栅、单一暖光"。
- 禁用空词：唯美、氛围感、高级、艺术感、电影感（不带方向/时间就是空）。
- 核实：仓库正文已核实（MIT）；"伪结构标签无效"属仓库红线，官方未提，标部分核实。

## 4 Seedream / 即梦官方四条（火山引擎文档）

1. **连贯自然语言**写"主体 + 行为 + 环境"，美学短词后置；长串碎片罗列会掉质量。
2. **画面文字加中文双引号**，并写位置（"标题文字为"小兔子找月亮"，放画面上方"）。
3. **参考图分两段写**："参考图1的人物五官与发型" + "生成她站在雨夜便利店门口……"；多图必须编号指名分工（"图1人物替换图2人物，参考图3的画面风格与配色"）。
4. **编辑指令三段式**："变化动作 + 变化对象 + 变化特征"，并强调"除修改处，其余保持不变"；避免"它/那个"这类模糊代词。

补充硬约束：图生图/编辑类提示建议 ≤120 字符，单条最长 800 字符，超长会出图异常或不生效；接口参数中**未见** `negative_prompt`，所以别指望否定词控负。
核实：官方指南四条已核实；长度与参数表部分核实；"组图"触发词（组图/一系列/帮我生成几张图）页面口径 10 张 vs 15 张不一致，标未统一。

## 5 一致性阶梯（style-consistency-ai 思路）

漂移时的修复顺序，从最小改动开始：

1. 换更好的参考图（首选，成本最低）
2. 收紧设定卡措辞（补齐缺失字段）
3. 删掉提示词里与参考图抢权的风格段
4. 重写整条提示词（最后手段）

配套原则：**只写增量**——参考图在场时，只描述"和上一张不同的部分"，风格词不再重复。
核实：仓库正文已核实；许可证未明示（NOASSERTION），只借思路不搬代码。

## 6 不要做的事（跨来源共同红线）

- 不做权重数字（`(word:1.2)`），即梦不保证生效。
- 不堆画质词（8K/超高清/大师作品/获奖摄影），不改变画面。
- 不写否定句（"不要杂乱"），改正向（"背景简洁"）。
- 不混风格（一张图一个风格词）。
- 不在一页塞多个时间点（单图只承载一个瞬间）。
- 不用具体艺术家名当风格（不稳定），改描述特征。
