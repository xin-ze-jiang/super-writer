# 视觉词条（六维度 · 可复制）

用法：按需挑词，每维度上限 2 个修饰词。词只写在对应段位，不跨段乱放。
所有词条都是「看得见的结果」，不是审美形容词。

## 1 构图 / 景别

| 要的效果 | 直接写 |
|---|---|
| 主体不呆板 | 主体位于画面右侧三分之一，眼睛在三分线交点 |
| 空得有理由 | 主体偏左，右侧大面积留白，背景简洁 |
| 视线被拉走 | 蜿蜒小路从画面左下延伸到远处主体 |
| 有层次 | 前景虚化、中景清晰主体、远景朦胧 |
| 主体被框住 | 门框/窗框把主体框在中央 |
| 景大人小 | 远景，人物占画面不到五分之一 |
| 全身+环境 | 全景，人物全身完整，脚下有地面 |
| 半身 | 中景，人物膝盖以上 |
| 表情为主 | 近景，人物胸部以上 |
| 五官细节 | 特写，脸部占画面三分之二 |
| 局部占满 | 大特写，只拍眼睛/手/纹理 |
| 显高大 | 低角度仰拍，天空占画面上半 |
| 显渺小 | 高角度俯拍，能看到地面 |
| 地平线 | 地平线放在画面下三分之一 |
| 秩序感 | 多个相同元素等距排列 |
| 动势 | 主体沿画面对角线排布 |

## 2 镜头

| 要的效果 | 直接写 |
|---|---|
| 透视夸张 | 广角，近处物体很大，远处建筑很小 |
| 强烈纵深 | 超广角，画面边缘拉伸 |
| 空间压缩 | 长焦，背景被压到主体身后 |
| 人脸不变形 | 85mm 人像镜头，面部比例自然，背景柔和虚化 |
| 接近肉眼 | 50mm 标准镜头 |
| 纹理放大 | 微距镜头，纹理占满画面，极浅景深 |
| 主体跳出 | 浅景深，背景虚化成柔和光斑 |
| 全清晰 | 全画面清晰，前景到远景都锐利 |
| 加层次 | 前景轻微虚化 |
| 有速度 | 奔跑姿态，四肢轻微运动模糊，背景拖影 |
| 冻住瞬间 | 高速摄影定格，水花悬停半空 |
| 平视自然 | 机位与人物眼睛齐平 |
| 人像常用 | 胸口机位 |
| 压迫感 | 机位贴地 |
| 俯视全局 | 机位在头顶上方俯视 |
| 不安动感 | 画面倾斜约 8~10 度，地平线是斜的 |

## 3 光线（方向 + 时间 + 光质）

方向：顺光（平）｜45 度侧光（立体）｜侧逆光（边缘发亮）｜逆光（近剪影）｜逆光+正面柔和补光｜正午顶光（压抑）｜底光（诡异）｜伦勃朗光（暗侧三角光斑）｜轮廓光（发丝肩线发亮）

时间：清晨微光（淡蓝清透）｜日出金光（暖橙低角度）｜正午强光（影子短硬）｜阴天散射（无影柔和）｜黄昏黄金时刻（暖橙长影）｜日落后蓝调时刻（深蓝天+地面暖灯）｜夜晚局部光源

光质/人工光：硬光（影子边缘锐利）｜柔光（过渡柔和）｜散射光（近无影）｜体积光（雾气尘埃中可见斜射光束）｜霓虹光（洋红+青蓝侧打）｜烛光（暖黄跳动）｜屏幕光（冷蓝正面）｜单一聚光灯（周围全黑）｜雨夜湿地面反射霓虹

## 4 色彩

## 5 材质（必须绑光学行为）

抛光金属（强反光，映出环境，边缘亮线）｜拉丝金属（细密平行纹）｜生锈铁（斑驳橘红剥落）｜哑光塑料（无高光）｜高光塑料（硬高光点）｜半透明亚克力（边缘透光）｜棉麻（编织纹理自然褶皱）｜丝绸（柔和高光垂坠）｜粗针织（绒面颗粒毛边）｜皮革（毛孔油亮磨损）｜短绒毛绒（边缘散毛，逆光透光）｜花岗岩（颗粒斑点）｜大理石（明显纹路）｜清水混凝土（气孔与模板痕）｜真实皮肤（毛孔可见，鼻尖额头微油光，肤色不均）｜皮肤透光（耳廓鼻翼边缘透红光）｜透明玻璃（背后物体折射变形，边缘亮线）｜磨砂玻璃（透光不透明）｜水面涟漪｜雨后湿地面镜面反射｜布料在膝部肘部自然堆叠｜灰尘指纹边缘磨损

写法四条：
1. 一次主推 1~2 种，写五种等于没写。
2. 材质配光写：硬光下皮革的毛孔。
3. 远景不写材质，只在中近景/特写用。
4. 不直译术语：不写"次表面散射"，写"皮肤透光，边缘透红光"。

## 6 风格（一张图只选一种）

摄影：纪实摄影（自然光、轻微颗粒、构图不完美）｜人像摄影（85mm、柔和侧光、浅景深、真实皮肤）｜商业产品摄影（纯色背景、柔光箱+一条硬边高光）｜复古胶片（暖黄、轻微漏光、颗粒、暗角）

3D：皮克斯三维动画（圆润、大眼、柔和皮肤透光）｜写实三维渲染（物理光照、真实毛孔与反光）｜黏土定格（指纹捏痕、哑光、微缩场景）｜低多边形（明显三角面、平面着色）｜赛博朋克三维（霓虹灯管、湿地面强反射、体积雾）｜等轴测（45 度俯视、平行投影、微缩模型）

绘画：水彩（透明叠色、湿边、纸纹、大量留白）｜油画厚涂（笔触明显、颜料堆叠反光）｜木刻版画（黑白刻线、刀痕、平涂套色）｜水墨（墨色浓淡、宣纸渗化、大面积留白）｜铅笔素描（灰阶、交叉排线、纸面颗粒）｜丙烯平涂（不透明色块、边缘利落）

插画：儿童绘本插画（柔和水彩、圆润造型、手绘线条、纸纹）｜扁平插画（纯色块无渐变、几何化）｜线条插画（清晰勾线+局部上色）｜国潮插画（中国元素、高饱和平涂、金色描边）｜杂志编辑插画（强构成、色块拼接、颗粒）

概念设计：电影场景概念设计（大气氛、环境叙事、前中后景分层）｜角色概念设定（纯色背景、正面站姿、全身完整、服装结构清晰）｜建筑空间概念（体块关系、结构线条、无人物）｜硬表面机甲（结构分件、金属与哑光塑料对比、工业标识）

## 7 冲突清单（同时出现 = 出图随机）

- 构图：三分法 + 中心对称 + 对角线；全身 + 特写；中景 + 近景。
- 镜头：广角 + 长焦；超广角 + 鱼眼；浅景深 + 全画面清晰；全景图写浅景深。
- 光线：逆光 + 正面清晰（缺"柔和补光"）；顶光 + 眼下无阴影；多主光方向。
- 色彩：高饱和 + 莫兰迪；高饱和 + 低饱和；五颜六色。
- 材质：金属 + 哑光 + 塑料同时主推；石头出塑料感（未写反射）。
- 风格：水彩 + 油画 + 厚涂；动漫 + 绘本；写实摄影 + 3D 渲染。
- 通用：8K / 超高清 / 大师作品 / 获奖摄影（无信息，只占字数）。

## 8 症状 → 一条修法

| 症状 | 改法 |
|---|---|
| 人物永远居中 | 加"主体偏右三分之一，左侧大面积留白" |
| 画面塞满 | 删环境形容词，加"背景简洁，主体周围留空" |
| 想要景大人小却出证件照 | 加"远景，人物占画面不到五分之一" |
| 人脸变宽 | 改"85mm 人像镜头，面部比例自然" |
| 背景抢戏 | 加"浅景深，背景虚化成柔和光斑" |
| 画面平 | 改"45 度侧光，一侧亮一侧暗" |
| 光束没出现 | 加"空气中漂浮尘埃，可见斜射光束" |
| 影子方向乱 | 全图只留一个主光，写明"主光来自画面左上" |
| 颜色脏 | 写"主色藏青与米白，其余克制，侧光" |
| 主体融进背景 | 写"主体深色，背景浅色，明度差明显" |
| 皮肤像塑料 | 加"毛孔可见，T 区微油光，肤色不均" |
| 金属像塑料 | 加"强反光，映出环境，边缘亮线" |
| 布料像纸 | 加"自然褶皱，膝部肘部堆叠" |
| 风格四不像 | 只留一个风格词，位置固定 |
| 绘本出成日漫 | 删"动漫/二次元"，改"儿童绘本插画，圆润造型，水彩上色" |
| 画面假 | 加"灰尘、指纹、边缘磨损" |
