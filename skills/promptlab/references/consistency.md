# 一致性控制

> 文字负责"是什么"，参考图负责"还是不是它"。缺一，系列图必崩。

## 1. 角色设定卡：8 字段固定顺序

顺序 = 权重。越不可变越靠前；把服装放最前，模型会为了配衣服重新捏脸，这是"脸变了"的头号原因。

| 序 | 字段 | 写到什么程度 |
|---|---|---|
| 1 | 身份 + 年龄 | "12 岁中国女孩"——定骨架与比例 |
| 2 | 脸型 + 五官 | 脸型、眼型与眼色、眉毛、鼻子、嘴唇，外加 1 个识别点（痣/疤/虎牙） |
| 3 | 发型 | 长度 + 刘海 + 分缝 + 发色 + 发质 + 扎法 + 发饰位置 |
| 4 | 体型 | 高矮、胖瘦、肩宽、四肢比例 |
| 5 | 标志物 | 1~2 个独一无二的物件（红绳、旧书包）——换场景最靠它认人 |
| 6 | 服装 | 每件分开写：颜色 + 材质 + 版型 + 细节（领口/袖口/扣子/图案位置） |
| 7 | 主色 | 写死 3 个颜色 |
| 8 | 画风 | 一句风格词，位置固定 |

**成品模板**

```
12岁中国女孩，圆脸，单眼皮，深棕色杏仁眼，眉毛细而平，鼻梁低，嘴唇薄且上唇略翘，左侧脸颊有一颗小痣；
黑色直发过肩，齐刘海，发尾微内扣，右侧别一枚黄色小鸭发夹；
身材瘦小，肩窄，四肢偏细；
左手腕系一条红绳；
上身穿米白色圆领棉麻短袖，袖口有一圈浅蓝细边，下身穿深蓝色宽松短裤，腰间系细棕色皮带；
整体配色米白、深蓝、暖黄；
儿童绘本插画风格，柔和水彩上色，圆润造型，手绘线条，轻微纸张纹理。
```

## 2. 世界设定卡（场景 / 3D 用）

| 字段 | 写什么 | 例子 |
|---|---|---|
| 世界观 | 时代 / 科技 / 社会基调 | 近未来东亚城市 |
| 建筑语汇 | 反复出现的形状与构件 | 白墙 + 木格栅 + 圆形暖光灯 |
| 材质体系 | 用哪几种材质，怎么组合 | 金属与竹材混用，表面哑光 |
| 主色 | 3 个颜色 | 米白 / 深灰 / 暖橙 |
| 时代细节 | 让世界可信的小物件 | 老式投币电话、纸质告示 |
| 天气基调 | 固定气候 | 常年阴天，湿地面 |
| 镜头风格 | 固定焦段与机位 | 固定 35mm，胸口机位 |

写法：`【世界卡逐字复制】+【本次镜头：地点 + 时间 + 人物 + 动作 + 景别 + 机位】`

同一世界换区域时，**只换地点名词，不换材质与配色**：巷子是青砖 + 木格栅，屋顶仍是青砖语汇 + 木格栅，只是换成瓦片与栏杆。

## 3. 跨图：一字不改 vs 必须换

| 类别 | 内容 | 规则 |
|---|---|---|
| 一字不改 | 身份年龄、脸型五官、发型、体型、标志物、主色、画风词 | 复制粘贴，连标点都不改，不换同义词 |
| 必须换 | 动作、表情、景别、机位、环境、时间、天气 | 逐张重写 |
| 半固定 | 服装 | 可换，但保留标志物，并写明"同一角色换了外套" |
| 受约束 | 光线 | 方向守轴线，只改强度与颜色 |

不要"优化"锚点里的同义词：把"齐刘海"改成"平刘海"、"单眼皮"改成"小眼睛"，模型会当成另一个人。

## 4. 只写增量（参考图在场时）

参考图已经在承担风格与身份，再写一大段风格词会与参考"抢权"，导致漂移。

- ✅ `保持参考图的脸型、发型、服装不变，只把表情改为微笑，背景换成教室`
- ❌ `参考图人物，日系水彩，柔光，浅景深，高级感，治愈系，少女感……`（与参考打架）

漂移时的修复顺序（从便宜到贵）：换更准的参考图 → 改锚点措辞一处 → 改镜头/环境 → 重写提示词 → 才考虑训练。

## 5. 轴线与光向（跨页不穿帮）

1. 定 180 度轴线：写死"A 在画面左，B 在画面右"，后续不许左右翻转
2. 光写"画面方向 + 受光部位"：固定一句"主光来自画面左上，人物右脸受光"，每张原样复制
3. 反打：写"反打，机位转到人物背后，主光仍在画面左上（此时人物左脸受光）"——方向不变，受光面随人转
4. 时间推进不改光向：黄昏到夜里，只改"光变弱、色变冷、加了路灯"
5. 一张图只有一个主光，其余是补光/环境光；多主光会让影子矛盾

## 6. 即梦实操锁一致（网页版）

1. 先只生成**角色设定图**（纯色背景、正面全身），抽到满意为止，这张是标准件
2. 之后每张用它作参考图，文字只负责动作与环境
3. 同一系列固定画幅比例；换比例会重新构图，脸也会跟着变
4. 固定种子可减随机，但换种子时优先保参考图，不要保种子
5. 每张出图后核对 3 点：脸型、发型、标志物；不符就重抽，别指望后期修
