# coordinate-plot / 坐标纸出图

把一组实验数据变成一张**物理尺寸真实的毫米方格纸图**：图上 1 小格就是 1 mm，5 小格是中格，10 小格是粗格。打印出来后可以直接照着数格子往纸质坐标纸上抄。

## 一、能做什么 / 不能做什么

**能：**
- 1mm 细格（浅灰）+ 5mm 中格（中灰）+ 10mm 粗格（近黑）三级网格，网格线严格与坐标刻度同源，从原点起算，不会错位
- 四种数据画法：`line` 折线直连 / `smooth` 三次样条平滑 / `fit` 线性拟合（标斜率、截距、R²）/ `scatter` 只画点
- 同一张画布里放 1 个或 2 个子图（上下排列），两个子图宽度严格对齐
- 同一子图可叠多条曲线（多 y 列），黑白时用实心/空心不同标记区分，彩色时用配色区分
- 中文轴标签、中文单位（`位置 x / mm`、`电阻 R / Ω`、`速度 v / (m·s⁻¹)`）
- 黑白打印优先：默认全黑线条文字；`--color color` 才上色
- 300dpi PNG，物理尺寸按毫米计算，打印时选"实际大小/100%"即为真毫米

**不能（明确边界）：**
- 不做实验报告的误差分析、不确定度计算、理论推导与讨论——本技能只负责出图
- 不支持对数坐标、误差棒、3 个以上子图、双 y 轴
- 不做数据拟合的模型选择（只提供一元线性最小二乘）
- 不生成 PDF/SVG 交付（需要时先出 PNG 再自行转换）

## 二、开工前必须确认的 5 件事

动手前先问清楚，缺一项就画不对，返工成本高：

1. **要不要拟合线？** 只画点 / 折线连 / 平滑曲线 / 线性拟合（拟合要不要写公式）
2. **几个子图？** 1 个还是 2 个
3. **怎么排？** 上下排列（本技能只支持上下；左右请在出图后自行拼）
4. **坐标纸还是普通网格？** 三级毫米格（默认）/ 只画大格 / 不画网格
5. **轴范围和刻度？** x、y 的上下限是多少，每大格代表多少（如 x 每大格 20 g，y 每大格 10 mm）
   —— 不确定时先让脚本自动定，出图后再核对数字是否好读

补充要问的：数据文件在哪、x/y 各是哪一列、轴标签怎么写（含单位）、标题要不要。

## 三、快速开始

在技能目录下执行（仓库里是 `skills/coordinate-plot`，装好后是对应工具的 `skills/coordinate-plot`）：

```bash
# 单幅图 + 线性拟合
python scripts/plot.py --csv examples/demo_spring.csv --x 0 --y 1 --mode fit --out 弹簧.png
```

```bash
# 上下两个子图：上=拟合，下=平滑曲线
python scripts/plot.py --csv examples/demo_spring.csv --x 0 --y 1 --mode fit \
  --panel-title "(a) 弹簧伸长量与砝码质量" \
  --panel2-csv examples/demo_rtd.csv --panel2-x 0 --panel2-y 1 --panel2-mode smooth \
  --panel2-title "(b) 热敏电阻的温度特性" \
  --out 双子图.png
```

Windows 可双击 `examples\run_example.bat`，会把两组示例图输出到 `output\`。macOS / Linux 没有 `.bat`，直接跑上面两条命令；省略 `--out` 时图片默认落在 CSV 同目录。

列可以写**列名**（带中文要加引号）或 **0 起的列序号**。表头里的列名会作为默认轴标签。

## 四、参数表

### 数据与子图
| 参数 | 默认 | 说明 |
|---|---|---|
| `--csv` | 必填 | 第一个子图的数据文件（CSV/TSV/空格分隔） |
| `--x` | `0` | x 列名或列序号 |
| `--y` | `1` | y 列，可多个：`--y U1 U2` 或 `--y U1,U2` |
| `--labels` | 列名 | 图例文字，逗号分隔，与 `--y` 一一对应 |
| `--panel2-csv` | 无 | 给了它才画第二个子图 |
| `--panel2-x` / `--panel2-y` | `0` / `1` | 第二子图的列 |
| `--panel2-labels` | 列名 | 第二子图图例 |
| `--panel2-mode` | 同 `--mode` | 第二子图连线方式 |
| `--no-header` | 关 | CSV 没有表头行时加 |
| `--delimiter` | `auto` | 分隔符；自动识别失败时手动指定（`,` `;` `\t` `" "`）|

### 画法
| 参数 | 默认 | 说明 |
|---|---|---|
| `--mode` | `line` | `line` 折线直连 / `smooth` 平滑 / `fit` 线性拟合 / `scatter` 只画点 |
| `--fit-span` | `axis` | 拟合线铺满整幅（`axis`）还是只覆盖数据段（`data`）|
| `--no-legend` | 关 | 不画图例（只有一条曲线时默认也不画）|

### 坐标与网格
| 参数 | 默认 | 说明 |
|---|---|---|
| `--xlim` / `--ylim` | 自动 | `"下限,上限"`，如 `--ylim 0,5`；自动模式会吸附到刻度整数倍并留 6% 余量 |
| `--panel2-xlim` / `--panel2-ylim` | 自动 | 第二子图范围 |
| `--xtick` / `--ytick` | 自动 | 每**大格**代表多少数据单位（如 `--xtick 20`）|
| `--panel2-xtick` / `--panel2-ytick` | 自动 | 第二子图大格间隔 |
| `--grid` | `mm` | `mm` 三级毫米格 / `normal` 只画大格 / `none` 不画网格 |

### 文字与输出
| 参数 | 默认 | 说明 |
|---|---|---|
| `--xlabel` / `--ylabel` | 列名 | 轴标签，建议写成 `物理量 符号 / 单位` |
| `--title` | 无 | 整张图标题（画在画布最上方）|
| `--panel-title` / `--panel2-title` | 无 | 子图左上角小标题，如 `(a) ...` |
| `--color` | `black` | `black` 黑白打印优先 / `color` 彩色 |
| `--dpi` | `300` | 输出分辨率 |
| `--out` | 与 CSV 同目录的 `<csv名>.png` | 输出路径 |
| `--font` | 自动 | 强制指定中文字体名 |
| `--label-font` / `--tick-font` / `--note-font` / `--legend-font` | 12.5 / 10.5 / 10 / 10 | 字号（pt）|

## 五、出图尺寸是怎么定的

- **1 个大格 = 10 mm**，所以版心宽度 = x 大格数 × 10mm，高度 = y 大格数 × 10mm。
- 大格数自动落在 4~12 之间（默认目标 9 格）；9 格 × 90mm 时整幅约 126×114mm（带子图标题 122mm），能塞进 A5。
- 想更大/更密：直接给 `--xtick` / `--ytick` 指定大格间隔，格数变了图就跟着变。格数太少（版心 < 70mm）会打印 `[warn]`，此时字会挤。
- 两个子图宽度必须一致，格子数少的那幅会把 **x 轴上限**（不是下限）扩到与另一幅相同，终端会打印扩到了多少。嫌范围难看就手动 `--xlim` 对齐。

## 六、常见坑（都是实测踩过的）

1. **别加 `bbox_inches='tight'`。** 它会把空白裁掉，1mm 就不等于 1mm 了。脚本里已固定为不使用。
2. **打印要选"实际大小 / 100%"**，否则会被缩放，格子就不是毫米了；缩到 A5 时整体等比缩，格子仍成比例。
3. `--xlim 0,5` 里的逗号必须是**英文逗号**；PowerShell 会把中文逗号当分隔符。
4. 自动范围会留 6% 余量并把边界吸附到刻度整数倍，所以出现 `-0.5` 这种下限很正常；不想要就显式给 `--xlim`。
5. 数据里的**空值、缺测行会被整行跳过**，脚本不插值；缺得多就会看起来少点。
6. 平滑曲线要求 x 递增；**x 有重复值会先合并取平均**。x 本身非单调（如滞回环）时自动改用参数样条，不会连成乱线。
7. 平滑只是视觉插值，**数据抖动大时会出现过冲**（曲线冲出数据点包围的范围）。要严谨就用 `fit` 或 `line`。
8. 拟合是普通最小二乘，**R² 高不代表物理关系成立**，别在报告里拿它当结论。
9. CSV 有"序号"列时，默认会把序号当 x。务必显式 `--x 时间列`。
10. 两个子图之间已留 22mm 间距（够放上图 x 标签 + 下图标题）；**自定义字号调大后**这个间距不会自动变大，可能压字。
11. 轴标签太长（超过 25mm 左边距）会被裁，请缩短或改用 `--label-font` 调小。
12. `examples\run_example.bat` 故意只写英文参数：Windows 批处理在 `chcp 65001` 下解析中文参数会乱码报错（实测）。要中文标题请直接在 PowerShell / 终端里跑命令。该脚本只有 Windows 能用，macOS / Linux 直接跑 `python scripts/plot.py ...`。

## 七、字体与跨平台

脚本启动时按顺序找第一个**本机真实存在**的中文字体，并把它作为首选写进 matplotlib 字体族：

`Microsoft YaHei` → `SimHei` → `SimSun` → `Noto Sans CJK SC` → `Source Han Sans SC` → `WenQuanYi Zen Hei` → `PingFang SC` → `Heiti SC` → `Arial Unicode MS` → `DejaVu Sans`（兜底，只用来补 `⁻ ¹ ²` 这类符号）

- **Windows**：默认命中 `Microsoft YaHei`，无需任何配置。
- **macOS**：命中 `PingFang SC` / `Heiti SC`；若都没有，用 `--font "STHeiti"`。
- **Linux**：需先装 `fonts-noto-cjk`（Debian/Ubuntu：`sudo apt install fonts-noto-cjk`），否则命中 `DejaVu Sans`，中文会变方块并打印 `[warn]`。
- 缺字时 matplotlib 会逐字回退到列表里的下一个字体，`m·s⁻¹`、`Ω`、`±`、`×10³` 均已实测正常。
- 如果终端打印 `Glyph ... missing from font(s)`，说明该字符连兜底字体都没有，换写法（如 `m/s`）或用 mathtext：`"$v$ / m·s$^{-1}$"`。

## 八、已知限制

- 只支持上下排列的 1~2 个子图，不支持左右排列、3 个以上子图。
- 只支持线性坐标，不支持对数坐标。
- 只做一元线性拟合，不支持多项式/指数拟合与误差棒。
- 网格线在最密（12 大格）时，1mm 线在 300dpi 下约 1.5px，屏幕上看偏浅，打印正常；若嫌浅可改 `scripts/plot.py` 顶部 `GRID_MINOR` 的颜色深度。
- 本技能只出图，不写实验报告的误差分析、理论讨论和结论。
